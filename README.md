# KIGO – THE TAMIL NADU OPEN WORLD

A 3D Third-Person Open-World Action-Adventure inspired by the cities, villages, culture, and highways of Tamil Nadu, India — built with **React**, **TypeScript**, **Three.js**, **Tailwind CSS**, and **Web Audio API**, plus a full **Godot 4 & GDScript (Stages 1–9)** architecture reference.

## World & Regions

- **Villupuram (Starting Hub)**: Friends Tea Kada (`டீ கடை`), Villupuram Bus Stand, Villupuram Railway Junction with train coach, Dravidian Temple Gopuram, Govt Hospital, College, and Market.
- **Villupuram Paddy Fields & Farm Village**: Green agricultural fields, traditional farmsteads, and tractor sheds.
- **Pondicherry Coastal Town**: French-Tamil heritage architecture, Lighthouse, Promenade Road, and Bay of Bengal beach where you can swim.
- **Chennai Metropolitan City**: NH-32 Highway arrival, Chennai Central Heritage Station, and high-rise skyline.

## Features

- **5 Original Friends & Story Chapters**: Arjun "Kigo", Kavin, Meera, Selva, and Ananya with Tamil script + English subtitle dialogues.
- **7 Indian Road Vehicles**: Auto-Rickshaw, Tamil Nadu Express Bus, Motorcycle, Scooter, Car, Tractor, and TN Police Jeep (`E` to drive/exit, `H` for vehicle horn) + living AI highway traffic.
- **Tamil Culture & Outfits**: Switch between White Veshti & Shirt, Festival Pattu Silk, Saree, Salwar Suit, College Uniform, TN Police Khaki, and Modern Casual.
- **Tea Kada & Food Inventory**: Buy and consume Degree Filter Coffee, Masala Dosa, Madurai Bun Parotta, Tender Coconut, and Temple Prasad.
- **Dynamic Weather & Day/Night Cycle**: Morning Sun, Pondicherry Dusk, Chennai Night with glowing streetlamps, Monsoon Rain, and Thunderstorms.
- **Save & Continue**: Persistent progress via `localStorage` + Fast Travel across Tamil Nadu.

## Controls

- **Move**: `W A S D`
- **Sprint**: `Shift`
- **Jump**: `Space`
- **Crouch**: `C`
- **Talk / Visit Tea Shop**: `F`
- **Enter / Exit Vehicle**: `E`
- **Vehicle Horn**: `H`
- **World Map & Missions**: `M`
- **Pause**: `Esc`

## Local & GitHub Pages Deployment

```bash
npm install
npm run dev
npm run build
```

Push to `main` and enable **Settings → Pages → Source: GitHub Actions** to publish automatically via `.github/workflows/deploy.yml`.
